# PaperStore PM

Sitio en español de Chile para una librería técnica, papelería y tienda de regalos en Puerto Montt. Leer README.md, FUENTES.md y TRASPASO.md.

- Esta entrega es una maqueta estática, sin servidor de negocio. No confundir demostración con servicio activo.
- Mantener foco en productos, opiniones y trabajos de la comunidad. No agregar pagos ni carrito sin solicitud.
- No inventar productos, reseñas, trabajos, horarios, precios, stock ni autorizaciones. Mantener fuentes de contenido.
- Nunca publicar envíos de clientes sin aprobación de la dueña. La autorización y la consulta de pendientes deben protegerse en el servidor cuando se implemente la plataforma real.
- Mantener datos de contacto privados, credenciales y archivos de clientes fuera del repositorio.
- Editar contenido en content.js. Mantener rutas relativas para GitHub Pages y Cloudflare.
- Ejecutar npm run build y revisar las páginas y el flujo afectado antes de entregar cambios.
- Publicar o transferir solo cuando el alcance de la solicitud lo incluya; la prioridad actual es maqueta y estructura.
